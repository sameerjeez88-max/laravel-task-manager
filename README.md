# 📋 Laravel Task Management System

A modern, secure, and fully functional task management web application built with Laravel. This project demonstrates full-stack development skills including authentication, CRUD operations, database relationships, and responsive UI design.

## 🚀 Features
- **User Authentication:** Secure Login & Registration system using Laravel Breeze.
- **Task Management:** Create, Read, Update, and Delete (CRUD) tasks.
- **Priority Management:** Assign priorities (Low, Medium, High) with visual color coding.
- **Due Date Tracking:** Set deadlines for tasks and track them easily.
- **User-Specific Data:** Each user can only see and manage their own tasks.
- **Responsive UI:** Built with Tailwind CSS for a clean and modern look on all devices.

## 🛠️ Tech Stack
- **Backend:** Laravel 11, PHP 8.x
- **Database:** MySQL
- **Frontend:** Blade Templates, Tailwind CSS, Alpine.js
- **Authentication:** Laravel Breeze
